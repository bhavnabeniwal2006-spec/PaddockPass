ABOUT PADDOCK PASS

MORE THAN JUST A RACE.

Paddock Pass is an F1 information website created for fans who want to explore the world of Formula 1 in one place.

From driver profiles and team information to famous circuits, this website brings together different parts of the sport in a simple and easy-to-explore format.

This project was developed as part of a learning journey in web development using HTML, CSS and Python Flask.
